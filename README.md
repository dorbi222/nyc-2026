# NYC 2026 – עדכון עיצוב

## איך מעלים את העדכון
1. בריפו `nyc-2026` בגיטהאב: **Add file** ← **Upload files**.
2. גוררים את כל הקבצים מהתיקייה הזו. הם מחליפים את הקיימים.
3. **Commit changes**, ומחכים לווי הירוק בלשונית **Actions**.
4. פותחים את האתר ומרעננים פעם אחת.

ה־config של פיירבייס כבר בפנים, לא צריך להדביק שוב.
את הקבצים `map-brothers.csv` ו־`map-mba.csv` אפשר למחוק מהריפו. המפה החדשה לא צריכה אותם.

## המפה
נטענת לבד. בכניסה הראשונה למפה היא ממקמת את הנקודות (בערך דקה), שומרת את המיקומים, ומאז זה מיידי לכולם.
מוסיפים עצירה עם כתובת בלו"ז והיא מופיעה על המפה לבד.
